# Section hero images

Drop a hero image in this folder named after the section's **route** and it
appears automatically at the top of that section page — no code change needed
(`SectionView.astro` globs this directory). Until an image is present, the
section falls back to a clean text header.

| Section              | Filename                    |
| -------------------- | --------------------------- |
| The Shadowed Mirror  | `the-shadowed-mirror.webp`  |
| Reentry Realities    | `reentry-realities.webp`    |
| Reflections          | `reflections.webp`          |
| The Deep Well        | `the-deep-well.webp`        |

`.webp`, `.jpg`, `.jpeg`, and `.png` all work (`.webp` preferred for size).
Recommended ~1600×900, landscape 16:9. The title is overlaid on a dark
bottom-up scrim, so images that are a little darker toward the lower third
read best.
